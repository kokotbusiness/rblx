One line to connect your game

Report progress from anywhere on the server. Quests listening to that event update and the UI refreshes.

local Kit = require(game.ServerScriptService.StarterKitServer.StarterKitService)

-- an enemy died, a coin was collected, a lap was finished...
Kit.recordQuestEvent(player, "EnemyKilled", 1)
Kit.addCurrency(player, "Coins", 25)
Kit.giveItem(player, "potion", 1)

-- KitConfig.luau: add a quest
{ id = "kill_10", event = "EnemyKilled", target = 10, title = "Defeat 10 enemies",
  reward = { currency = "Coins", amount = 120 } },

FAQ

Do I need Rojo or VS Code?

No. Open the demo place in Roblox Studio and copy three folders into your game. Rojo is optional.

Is the spin wheel a paid loot box?

No. It is free, once per day, and shows its odds. If you make spins purchasable, Roblox’s rules for paid random items apply – check them first.

Will developer products be granted twice?

The receipt handler remembers purchase IDs, only confirms after saving, and is covered by unit tests for duplicates and failed grants.

Does it work with ProfileStore / my own data system?

Yes. The game logic modules are pure Luau with no Roblox calls; the saving layer is one file you can swap.

Can I resell it?

No. You can use it in any number of your own games, including commercial ones, but not redistribute the source.
