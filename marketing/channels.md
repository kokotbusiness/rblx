# Where the owner could legitimately promote the kit

Rules change. **Before posting, open each venue's current rules and follow them.** If paid
promotion isn't allowed, don't post the link there – contribute help instead, or skip it.
Nothing here has been posted; this system never posts.

| # | Venue | How to use it legitimately | Check before posting |
|---|-------|----------------------------|----------------------|
